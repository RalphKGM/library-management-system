LIBRARY DEMO FOR WINDOWS

1. Install Python 3.9 or newer if it is not installed
2. Extract the entire ZIP to a folder
3. Double-click run-demo.bat
4. The first run installs Flask, so internet access is needed once
5. Your browser opens when the server is ready
6. Keep the command window open during the demo. Press Ctrl+C to stop
